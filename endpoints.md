# Tables

### USERS

- id: number
- email: string
- password: string // Никогда не отсылать с общими данными
- username: string
- theme: string
- info: string
- avatar_link: string
- created_at: string
- is_admin: boolean
- is_online: boolean
- last_seen: string
- is_email_accepted: boolean
- contacts: number[] // Возможно придётся хранить другой формат (JSON[]), т.к. для себя можно изменять имена и аватарки пользователей // Не отсылать с общими данными, будет отдельный эндпоинт
- enemies_id: number[] // Не отсылать с общими данными, будет отдельный эндпоинт
- is_muted_chats_id: number[]
- is_pinned_chats_id: number[]

### CHATS

- id: number // Не должны повторятся в GROUPS
- first_person_id: number
- second_person_id: number
- created_at: string

### GROUPS

- id: number // Не должны повторятся в CHATS
- owner_id: number
- name: string
- info: string
- users_id: number[]
- admins_id: number[]
- enemies_id: number[]
- created_at: string

### MESSAGES

- id: number
- user_id: number
- where_id: number
- text: string
- status: string
- is_pinned: boolean
- created_at: string
- is_changed: boolean
- is_forwarded: boolean
- type: string
- file_link: string

### TOKENS

- id: number
- user_id: number
- token: string

# List module

В каждом запросе вместе с путем и телом запроса отправляется httpOnly cookie, в котором хранится token пользователя.

## GET /list/{user_id}/chats - Получить список чатов пользователя

### Response:

**200**

```js
{
    "status": 200,
    "message": "Успешно получили список чатов пользователя",
    "body": массив элементов CHATS
}
```

| **Статус код** |                **Сообщение**                 |               **Когда происходит**               |
| :------------: | :------------------------------------------: | :----------------------------------------------: |
|      404       |   Пользователя с таким айди не существует    |     Когда айди из ссылки не существует в БД      |
|      429       | Необходима авторизация для использования api |            Когда токена нет в запросе            |
|      430       |               Невалидный токен               |         Когда токен из запроса невалиден         |
|      500       |                Ошибка сервера                | Когда происходит любая ошибка на стороне сервера |

# Registration module

## POST /registration - Создание нового пользователя

### Request:

```js
{
    "email": string,
    "password": string,
    "username": string
}
```

### Response:

**200**

```js
{
    "status": 200,
    "message": "Пользователь успешно создан",
    "body": null
}
```

| **Статус код** |                  **Сообщение**                  |                **Когда происходит**                |
| :------------: | :---------------------------------------------: | :------------------------------------------------: |
|      400       |       Данный домен почт не поддерживается       | Когда вид почты нормальный, а домен подозрительный |
|      404       | Пользователь с такой почтой уже зарегистрирован |             Такая почта уже есть в БД              |
|      500       |                 Ошибка сервера                  |  Когда происходит любая ошибка на стороне сервера  |

# Auth module

## POST /auth - Аунтетификация пользователя по его данным

Данный эндпоинт устанавливает httpOnly cookie, содержащий авторизационный токен пользователя.

### Request:

```js
{
    "email": string,
    "password": string
}
```

### Response:

**200**

```js
{
    "status": 200,
    "message": "Вы успешно вошли в свой аккаунт",
    "body": null
}
```

| **Статус код** |                   **Сообщение**                    |               **Когда происходит**               |
| :------------: | :------------------------------------------------: | :----------------------------------------------: |
|      400       |            Неверный пароль от аккаунта             |        Пароль не сходится с тем, что в БД        |
|      404       | Пользователь с такой почтой еще не зарегистрирован |           Когда данной почты нет в БД            |
|      500       |                   Ошибка сервера                   | Когда происходит любая ошибка на стороне сервера |

**500**

```js

     "body": null
}
```
